## Typical scenarios
- Unblock mistakenly blocked domains
- Allow access to previously restricted sites
- Update security policies by removing blocks

## Workflow
1. Verify domain should be unblocked
2. Call tool with domain parameter

## Parameters
- **domain** (required): The domain to unblock

## Parameter aliases
domain: website, site, url, domain name

## Call examples
- "Unblock example.com"
- "Allow access to business-site.org"
- "Remove block from website.net"
