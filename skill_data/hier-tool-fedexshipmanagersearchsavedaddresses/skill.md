## Typical scenarios
- Looking for customer's shipping address
- Finding frequently used business addresses
- Verifying address details before shipping

## Tool-call workflow
1. Enter search term (name, street, city, etc.)
2. Call tool with search_term
3. Review returned address matches

## Parameters
**Required:**
- search_term: Text to search in address details

## Parameter aliases
- search_term: name/address/location/contact

## Call examples
1. "Find John Smith's address"
2. "Search for addresses on Main Street"
3. "Look up saved addresses for Acme Corp"
4. "Find my business address"
