## What this category is for
This category enables interaction with healthcare services (like Teladoc), clinical record systems (like EpicFHIR), and genetic data platforms (like 23andMe). Use it to access medical records, manage appointments, consult doctors, handle prescriptions, and work with genetic data including insights, sharing, and privacy settings.

## How to decide when to use this category
Use this category when the user request involves:
- Healthcare services: appointments, consultations, prescriptions, medical history, doctor reviews.
- Clinical records: downloading files, updating patient records, or managing clinical documents in an EHR.
- Genetic data: retrieving, analyzing, sharing, or managing privacy of genetic information.
- Health data integration: accessing or updating personal health records.

## Mandatory workflow
1. Read this big skill first to understand the category scope.
2. Identify which specific tool matches the user's request.
3. Read the relevant small skill for that tool before making any API calls.
4. Follow the small skill's guidance for parameters, examples, and workflows.
