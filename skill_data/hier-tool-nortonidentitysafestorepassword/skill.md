## Typical scenarios
- Save new account password
- Store generated password
- Add login credentials for new service

## Workflow
1. Collect password, website, and username
2. Call tool with all parameters

## Parameters
- **password** (required): Password to store
- **website** (required): Associated website
- **username** (required): Associated username

## Parameter aliases
password: pass, pwd, secret
website: site, url, web_address
username: user, login, account_name

## Call examples
- "Store password for gmail account"
- "Save new banking password"
- "Add login credentials for new service"
