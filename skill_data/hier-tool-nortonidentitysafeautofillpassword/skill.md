## Typical scenarios
- Quick login to frequently used sites
- Secure password entry without typing
- Automated form filling

## Workflow
1. Navigate to target website
2. Call tool with website parameter

## Parameters
- **website** (required): Website URL

## Parameter aliases
website: site, url, web_address, domain

## Call examples
- "Auto-fill password on gmail.com"
- "Fill login for amazon.com"
- "Auto-fill on banking site"
