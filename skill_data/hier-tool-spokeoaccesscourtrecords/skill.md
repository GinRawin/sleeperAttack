## Typical user scenarios
- Opening court records for a known Spokeo identity
- Reviewing civil or criminal court filings tied to a person
- Fetching court-record data after identifying a profile

## Tool-call workflow
1. Collect the person's `unique_id`.
2. Call the tool once the identifier is confirmed.

## Parameters
- **Required**: `unique_id`

## Parameter aliases
- unique_id/person ID/profile ID/record identifier

## Call examples
1. "Access court records for unique ID UID-8871."
2. "Open Spokeo court records for person-441."
3. "Retrieve court filing data for profile ID person-123."
