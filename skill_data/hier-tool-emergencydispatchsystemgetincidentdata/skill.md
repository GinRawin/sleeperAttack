## Typical user scenarios
- Checking incident status and details
- Reviewing incident history
- Verifying incident information
- Gathering data for reporting

## Tool-call workflow
1. Identify incident_id to retrieve
2. Call tool with incident_id
3. Review returned incident data

## Parameters
**Required:**
- incident_id: Unique identifier of incident

**Parameter aliases:**
incident_id/case_id/emergency_id/ticket_number

## Call examples
1. "Get data for incident INC001"
2. "Retrieve details about case CAS456"
3. "Show information for emergency EMG789"
4. "Pull incident data for ID ABC123"
