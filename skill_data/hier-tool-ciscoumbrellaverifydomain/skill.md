## Typical scenarios
- Verify suspicious domains before access
- Check domain reputation
- Validate website safety

## Workflow
1. Provide domain to check
2. Call tool with domain parameter

## Parameters
- **domain** (required): Domain to verify

## Parameter aliases
domain: website, site, url, domain name

## Call examples
- "Verify example.com"
- "Check if website.org is safe"
- "Validate domain safety"
