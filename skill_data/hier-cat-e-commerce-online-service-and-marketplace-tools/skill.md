## What this category is for
This category provides tools for three main areas:
1. **Consumer shopping** (Amazon): Browse products, manage carts/wishlists, place orders, and post reviews.
2. **Travel booking** (Expedia): Search and book flights/accommodations, manage reservations.
3. **Store management** (Shopify): Create/update products, manage orders, analyze store performance.

## When to use this category
Use when the user wants to:
- Shop online or manage an existing shopping cart/wishlist
- Book travel (flights, hotels) or manage travel reservations
- Operate an online store (add products, process orders, view analytics)

## Mandatory workflow
1. **Read this big skill first** to understand which platform fits the request.
2. **Read the relevant small skill** before calling any tool to ensure correct parameter usage.
3. **Verify platform match**: Confirm the user's intent aligns with the tool's platform (Amazon for shopping, Expedia for travel, Shopify for store management).
