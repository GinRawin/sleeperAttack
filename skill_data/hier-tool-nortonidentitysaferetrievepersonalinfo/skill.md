## Typical scenarios
- View saved address details
- Check stored payment information
- Retrieve personal data for forms

## Workflow
1. Specify information type needed
2. Call tool with info_type parameter

## Parameters
- **info_type** (required): 'address' or 'payment'

## Parameter aliases
info_type: type, information_type, data_type

## Call examples
- "Retrieve my address information"
- "Get stored payment details"
- "Show saved personal info"
