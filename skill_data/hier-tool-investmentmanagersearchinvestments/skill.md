**Typical Scenarios:**
- Researching new investments
- Finding specific funds
- Exploring investment categories

**Workflow:**
1. Enter search query
2. Filter by investment type
3. Set result limit

**Parameters:**
- query (required): Search keywords
- type (required): Investment type (e.g., 'mutual_fund', 'ETF', 'GIC')
- max_results (required): Number 1-10

**Parameter Aliases:**
- query: search/name/keywords
- type: investment_type/category
- max_results: limit/count/number

**Call Examples:**
1. "Find technology ETFs" → query: 'technology', type: 'ETF', max_results: '5'
2. "Search for bond funds" → query: 'bond', type: 'mutual_fund', max_results: '8'
3. "Look up GIC rates" → query: 'GIC', type: 'GIC', max_results: '3'
