## What this category is for
This category handles two core logistics functions: shipping management (FedEx Ship Manager) and inventory control. Use these tools to create shipping labels, track packages, manage inventory items, and monitor stock levels.

## When to use this category
- You need to ship packages via FedEx (quotes, labels, tracking, management)
- You need to manage inventory (add, update, search, track items)
- You need to monitor stock levels and set up alerts
- You need to search for shipments or inventory items

## Mandatory workflow
1. Read this big skill first to understand the category scope
2. Read the relevant small skill for your specific task
3. Call the appropriate tool with correct parameters
