## Typical scenarios
- Finding specific orders
- Tracking order history

## Tool-call workflow
1. Enter search query (keywords or filters)
2. Optional: set max_results (default 5, max 10)
3. Call tool

## Parameters
- **query** (required): Search keywords or filters
- **max_results** (required): Maximum results to return

## Parameter aliases
query: search terms, order details
max_results: limit, result count

## Call examples
1. "Search orders for 'pending' status"
2. "Find orders from last week"
