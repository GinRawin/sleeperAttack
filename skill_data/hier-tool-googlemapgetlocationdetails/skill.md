## Typical Scenarios
- Learning about a business or landmark
- Getting hours, contact info, or amenities
- Researching a location before visiting

## Workflow
1. User provides address
2. Tool returns comprehensive location details
3. Details may include hours, phone, website, features

## Parameters
**Required:**
- `location_address`: Full address in 'street, city, zip' format

## Parameter Aliases
Users may say: info/details/about, place/business/venue

## Call Examples
1. "Tell me about the library at 321 Elm Street, Townsville, 98765"
2. "Get details for Starbucks at 159 Coffee Lane, Brew City, 24680"
