## Typical Scenarios
- Cleaning up old tweets
- Removing incorrect information
- Batch deletion of multiple tweets

## Workflow
1. Confirm deletion is intended
2. Gather tweet_ids array
3. Call tool with tweet_ids

## Parameters
**Required:**
- `tweet_ids`: Array of tweet identifiers

**Aliases:** tweet_ids → tweets/IDs

## Examples
1. "Delete tweets 12345 and 67890"
2. "Remove my tweets with IDs ABCDE, FGHIJ"
3. "Delete these three tweets"
