## Typical scenarios
- Find password for specific website
- Search passwords by keyword
- Locate stored login credentials

## Workflow
1. Define search query
2. Set result limit if needed
3. Call tool with parameters

## Parameters
- **query** (required): Search query
- **max_results** (required): Maximum results (default 10)

## Parameter aliases
query: search_term, keyword, term
max_results: limit, count, results_limit

## Call examples
- "Search passwords for 'bank'"
- "Find login for amazon"
- "Search stored credentials"
