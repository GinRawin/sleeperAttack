## Typical user scenarios
- Finding previously visited sites
- Locating specific history entries
- Reviewing past browsing
- Recovering lost URLs

## Tool-call workflow
1. Define search query
2. Call tool with query
3. Review matching results

## Parameters
**query** (required): Search term for history

## Parameter aliases
query: search_term, keyword, term

## Call examples
1. {"query": "shopping"}
2. {"query": "news articles"}
3. {"query": "documentation"}
