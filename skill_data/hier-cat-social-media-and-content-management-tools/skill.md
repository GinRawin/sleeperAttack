## Purpose
This category enables applications to interact with social media platforms (Facebook, Twitter) for posting content, managing profiles, engaging with others, and searching information.

## When to Use
Use these tools when the user needs to:
- Create, read, update, or delete social media posts
- Manage user profiles and settings
- Send messages or engage with other users (comments, likes, follows)
- Search for content, friends, or tweets
- Perform batch operations (delete multiple tweets, follow multiple users)

## Mandatory Workflow
1. **Read this big skill first** to understand the category scope and safety requirements.
2. **Read the relevant small skill** for the specific tool you plan to use.
3. **Call the tool** with properly formatted parameters.
