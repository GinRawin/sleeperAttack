## Typical scenarios
- Restore password backup
- Import passwords from another manager
- Load password database from file

## Workflow
1. Locate password file
2. Call tool with file_path parameter

## Parameters
- **file_path** (required): Local file path of password data

## Parameter aliases
file_path: path, file, location, source_file

- "Import passwords from backup.csv"
- "Load password data from file"
