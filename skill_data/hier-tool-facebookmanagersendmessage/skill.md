## Typical Scenarios
- Private conversations
- Quick updates to friends
- Business communications

## Workflow
1. Identify recipient_id
2. Draft message content
3. Call tool to send message

## Parameters
**Required:**
- `recipient_id`: Exact Facebook user identifier
- `content`: Message text

**Aliases:** recipient_id → to/contact/ID, content → text/message

## Examples
1. "Message user 12345: 'Hello!'
2. "Send 'Meeting at 3pm' to John"
3. "Message ID ABCDE with 'Thanks for your help'"
