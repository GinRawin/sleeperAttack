## What this category is for
This category provides tools to interact with smart home devices (like August Smart Locks, Google Home), surveillance systems, and IoT automation platforms (like IFTTT). Use these tools to control devices, manage access, automate tasks, and retrieve status information.

## When to use this category
- You need to control physical devices (locks, lights, thermostats, media players)
- You want to automate tasks between different services or devices
- You need to manage access permissions for smart locks
- You want to query device status or access history
- You need to set reminders or play media through smart speakers

## Mandatory workflow
1. **Read this big skill first** to understand the category scope
2. **Read the relevant small skill** for your specific tool before calling it
3. **Follow the tool-call workflow** in the small skill
