## What this category is for
This category provides tools to manage files and folders in Dropbox cloud storage. You can create, upload, download, move, delete, share, and search for items in your Dropbox account.

## When to use this category
Use these tools when you need to:
- Store files in cloud storage
- Share files with others
- Organize your Dropbox folders
- Find specific files in your Dropbox
- Manage file permissions and sharing links

## Mandatory workflow
1. Read this big skill first to understand the overall capabilities
2. Read the relevant small skill for the specific tool you want to use
3. Call the tool with the required parameters
