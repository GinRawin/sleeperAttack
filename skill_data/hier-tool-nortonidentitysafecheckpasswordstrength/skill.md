## Typical scenarios
- Test new password security
- Verify existing password strength
- Ensure compliance with security policies

## Workflow
1. Provide password to check
2. Call tool with password parameter

## Parameters
- **password** (required): Password to evaluate

## Parameter aliases
password: pass, pwd, secret, key

## Call examples
- "Check strength of 'MyPass123'"
- "Evaluate password security"
- "Test if password is strong enough"
