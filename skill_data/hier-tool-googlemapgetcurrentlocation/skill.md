## Typical Scenarios
- Finding where the user is right now
- Using current location as starting point for directions
- Searching for nearby places relative to current position

## Workflow
1. Tool detects device location
2. Returns current coordinates and address
3. Can be used as default for other tools

## Parameters
**None required** - tool uses device GPS/location services

## Parameter Aliases
Users may say: my location/where am I/current position/here

## Call Examples
1. "Where am I right now?"
2. "Get my current location coordinates"
