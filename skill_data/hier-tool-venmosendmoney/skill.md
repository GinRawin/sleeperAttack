**Typical Scenarios:**
- Paying friends back
- Splitting costs
- Sending gifts

**Workflow:**
1. Identify recipient username
2. Confirm payment amount
3. Add optional note

**Parameters:**
- recipient_username (required): Recipient's Venmo username
- amount (required): Positive number
- note (required): Optional message

**Parameter Aliases:**
- recipient_username: to/recipient/user
- amount: payment/send/value
- note: message/description

**Call Examples:**
1. "Send $25 to @sarah" → recipient_username: 'sarah', amount: '25', note: ''
2. "Pay Tom $40 for dinner" → recipient_username: 'tom', amount: '40', note: 'Dinner last night'
3. "Transfer $15 to mom" → recipient_username: 'mom', amount: '15', note: 'Love you!'
