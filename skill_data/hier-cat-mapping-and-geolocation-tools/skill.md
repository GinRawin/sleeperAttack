## Purpose
This category provides geolocation, mapping, and navigation capabilities. Use it when you need to:
- Find locations, addresses, or points of interest
- Get directions between places
- Convert addresses to coordinates (geocoding) or coordinates to addresses (reverse geocoding)
- Access current location or location details
- Manage saved addresses in an address book

## When to Use
Choose this category when the user request involves:
- Finding or navigating to physical locations
- Getting distance, directions, or travel times
- Looking up address information or coordinates
- Searching for nearby places or businesses
- Managing saved locations

## Workflow Requirement
1. ALWAYS read this big skill first to understand the category scope
2. Then read the specific small skill for the tool you plan to use
3. Only call tools after understanding both the category context and specific tool usage
