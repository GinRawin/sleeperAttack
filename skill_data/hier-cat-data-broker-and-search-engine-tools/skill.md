## What this category is for
These tools provide access to aggregated personal data from data brokers and search engine data from platforms like Google. Use them to retrieve search histories, analyze trends, perform various types of searches, and interact with web browsers programmatically.

## When to use this category
- Researching search trends or patterns
- Analyzing user search behavior
- Gathering information from search engines
- Automating web browser interactions
- Retrieving historical browsing or search data

## Mandatory workflow
1. Read this big skill first to understand category scope
2. Read the relevant small skill for your specific tool
3. Call the tool with proper parameters
