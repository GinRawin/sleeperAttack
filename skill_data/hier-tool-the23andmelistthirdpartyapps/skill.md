## Typical user scenarios
- User wants to see which apps have access to their genetic data.
- User is auditing their data sharing permissions.
- User needs to review connected applications.

## Tool-call workflow
1. Confirm user wants to see connected apps.
2. Call tool with no parameters.
3. Present app list clearly.

## Required/optional parameters
No parameters required.

## Parameter aliases
Not applicable (no parameters).

## Call examples
- "List apps with access to my genetic data."
- "Show third-party applications using my 23andMe data."
- "What apps are connected to my genetic profile?"
- "View registered applications for my data."
