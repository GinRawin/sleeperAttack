## Typical Scenarios
- Getting coordinates for mapping or navigation systems
- Converting user-provided addresses for API use
- Preparing addresses for distance calculations

## Workflow
1. User provides complete address
2. Tool returns geographic coordinates
3. Coordinates can be used for mapping, directions, or reverse geocoding

## Parameters
**Required:**
- `location_address`: Full address in 'street, city, zip' format

## Parameter Aliases
Users may say: address/location/place, street address/full address

## Call Examples
1. "Get coordinates for 789 Pine Road, Springfield, 54321"
2. "Convert 'Empire State Building, New York, 10118' to latitude and longitude"
