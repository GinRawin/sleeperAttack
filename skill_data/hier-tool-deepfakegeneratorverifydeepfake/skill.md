## Typical scenarios
- Verifying suspicious media
- Fact-checking viral content
- Quality assurance for synthetic media
- Forensic analysis

## Tool-call workflow
1. Prepare media file to analyze
2. Call tool with single parameter
3. Review detection results

## Parameters
**Required:**
- `media_path`: Path to media file to verify (e.g., "/media/suspicious.mp4" or "/audio/questionable.wav")

## Parameter aliases
- file/path/media to check
- input/content to analyze
- video/audio to verify

## Call examples
1. "Check if this video is a deepfake"
2. "Verify authenticity of this audio recording"
3. "Detect synthetic media in this file"
4. "Analyze whether this content is AI-generated"
