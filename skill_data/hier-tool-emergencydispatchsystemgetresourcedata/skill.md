## Typical user scenarios
- Checking resource status and availability
- Reviewing resource capabilities
- Verifying resource assignment
- Gathering resource history

## Tool-call workflow
1. Identify resource_id to retrieve
2. Call tool with resource_id
3. Review returned resource data

## Parameters
**Required:**
- resource_id: Unique identifier of dispatch resource

**Parameter aliases:**
resource_id/unit_id/vehicle_id/asset_id

## Call examples
1. "Get data for ambulance AMB001"
2. "Retrieve details about fire truck FTK005"
3. "Show information for police unit POL123"
4. "Pull resource data for ID RES456"
