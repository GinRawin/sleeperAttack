- Verifying account value
- Pre-trade balance confirmation

1. Identify account type
2. Retrieve current balance

**Parameter Aliases:**
- account: account_type/type/acct

**Call Examples:**
1. "What's my self-directed TFSA balance?" → account: 'self-directed TFSA'
2. "Check non-registered brokerage cash" → account: 'self-directed non-registered'
3. "Show available trading funds" → account: 'self-directed TFSA'
