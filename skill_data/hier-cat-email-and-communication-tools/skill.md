## What this category is for
This category provides tools for communication tasks: sending/receiving emails (Gmail), team messaging (Slack), and SMS/telecom operations (Twilio).

## When to use this category
Use when the user request involves:
- Sending, reading, or organizing emails
- Managing email contacts
- Sending Slack messages or managing channels
- Sending SMS messages or checking telecom information

## Mandatory workflow
1. Read this big skill first to understand the category scope.
2. Identify which specific tool matches the user's request.
3. Read the relevant small skill for detailed tool instructions.
4. Call the tool with properly formatted parameters.
