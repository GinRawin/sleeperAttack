## Typical user scenarios
- Removing outdated information
- Cleaning up old notes
- Deleting temporary drafts

## Tool-call workflow
1. Confirm deletion with user.
2. Provide required `note_id`.
3. Call the tool.

## Parameters
- **Required**: `note_id`

## Parameter aliases
- note_id/note/ID

## Call examples
1. "Delete note 'abc123'"
2. "Remove the note with ID 'xyz789'"
