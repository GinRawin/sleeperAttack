## What this category is for
This category enables cryptocurrency trading on exchanges like Binance and blockchain operations on platforms like Ethereum. It handles trading orders, account management, fiat deposits/withdrawals, price queries, and smart contract development/deployment.

## When to use this category
Use when the user wants to:
- Trade cryptocurrencies (buy/sell)
- Manage exchange accounts (deposit/withdraw funds, check balances)
- Query market data or transaction history
- Develop, deploy, or interact with Ethereum smart contracts
- Transfer Ether or query blockchain data

## Mandatory workflow
1. Read this big skill to understand category scope
2. Read the relevant small skill for the specific tool before calling
3. Verify all required parameters are collected
4. Execute tool call
