## What this category is for
This category helps you manage notes (Evernote), tasks (Todoist), and calendar events (Google Calendar). Use it to create, read, update, delete, and search your personal and work organization items.

## How to decide when to use this category
Use this category when the user wants to:
- Create or manage notes/notebooks (Evernote)
- Create or manage tasks with due dates and priorities (Todoist)
- Schedule, update, or search calendar events (Google Calendar)
- Set reminders for tasks or events
- Share tasks or notes with others

## Mandatory workflow
1. **Read this big skill first** to understand which tool family (Evernote/Todoist/Google Calendar) matches the user's request.
2. **Read the relevant small skill** for the specific tool before calling it.
3. **Verify parameters** match the tool's requirements.
4. **Execute the tool call** with proper parameter values.
