## Typical scenarios
- Block malicious or inappropriate websites
- Prevent access to phishing domains
- Enforce security policies by restricting domains

## Workflow
1. Confirm the domain needs blocking
2. Call tool with domain parameter

## Parameters
- **domain** (required): The domain to block (e.g., 'malicious-site.com')

## Parameter aliases
domain: website, site, url, domain name

## Call examples
- "Block example.com"
- "Block access to phishing-site.org"
- "Restrict badwebsite.net"
