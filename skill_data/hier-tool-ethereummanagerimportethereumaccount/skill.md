## Typical scenarios
- Restore existing wallet
- Import account for management
- Access existing funds

## Workflow
1. Get private_key from user
2. Call EthereumManagerImportEthereumAccount

## Parameters
- **private_key (required)**: Account private key

## Parameter aliases
- private_key: secret key, wallet key, private key

## Call examples
1. "Import my Ethereum account with private key"
2. "Restore wallet from private key"
3. "Add existing account"
