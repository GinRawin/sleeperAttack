## Typical scenarios
- Save shipping address for online shopping
- Store credit card information securely
- Keep personal details for auto-fill

## Workflow
1. Determine information type (address/payment)
2. Prepare data in correct format
3. Call tool with parameters

## Parameters
- **info_type** (required): 'address' or 'payment'
- **info_data** (required): Data object in specified format

## Parameter aliases
info_type: type, information_type, data_type
info_data: data, details, information

## Call examples
- "Store my home address"
- "Save credit card information"
- "Add payment details for checkout"
