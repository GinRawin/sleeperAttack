## Typical Scenarios
- Sharing life updates
- Posting photos/videos
- Announcing events
- Business promotions

## Workflow
1. Prepare post content
2. Select media file (if any)
3. Choose privacy setting
4. Call tool with all parameters

## Parameters
**Required:**
- `content`: Post text
- `media_path`: Local file path (image/video)
- `privacy_setting`: 'public', 'friends', or 'only me' (default: 'friends')

**Aliases:** content → text/message, media_path → file/path/image, privacy_setting → visibility/audience

## Examples
1. "Post 'Vacation time!' with photo at /photos/beach.jpg, friends only"
2. "Create public post: New blog article is live"
3. "Share private post: Personal reflection"
