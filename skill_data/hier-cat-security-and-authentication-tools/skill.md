## What this category is for
These tools handle security operations including domain blocking, policy management, threat analysis, and password/identity protection. Use Cisco Umbrella for network security and threat intelligence. Use Norton Identity Safe for personal password management and authentication.

## When to use this category
- Blocking or verifying suspicious domains
- Creating or managing security policies (whitelist/blacklist)
- Generating security reports or searching logs
- Managing passwords, enabling 2FA, or storing personal information securely
- Checking password strength or generating secure passwords

## Mandatory workflow
1. Read this big skill first to understand the category scope.
2. Read the relevant small skill for the specific tool you need.
3. Call the tool with proper parameters.
