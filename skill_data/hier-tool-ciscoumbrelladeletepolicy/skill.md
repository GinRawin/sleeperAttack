## Typical scenarios
- Remove outdated security policies
- Delete temporary policies after use
- Clean up unused policy configurations

## Workflow
1. Verify policy ID
2. Confirm deletion is intended
3. Call tool with policy_id

## Parameters
- **policy_id** (required): Unique policy identifier

## Parameter aliases
policy_id: id, policy identifier, policy number

## Call examples
- "Delete policy ID POL-12345"
- "Remove old marketing policy"
- "Delete temporary test policy"
