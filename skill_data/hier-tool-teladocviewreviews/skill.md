## Typical user scenarios
- User wants to check a doctor's ratings before booking.
- User is researching doctors and wants to see patient feedback.
- User needs to verify a doctor's reputation.

## Tool-call workflow
1. Get doctor_id from user.
2. Call tool with doctor_id parameter.
3. Present reviews clearly to user.

## Required/optional parameters
- doctor_id (required): Unique doctor identifier.

## Parameter aliases
- doctor_id: doctor, physician, provider

## Call examples
- "Show reviews for doctor DR123."
- "What are the ratings for physician PHY456?"
- "View feedback for doctor DOC789."
- "Check reviews for doctor DR101."
