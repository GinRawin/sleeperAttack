## What this category is for
This category provides tools for public-service operations such as emergency dispatch and traffic control. It allows you to create, edit, search, and manage emergency incidents, dispatch resources, coordinate emergency responses, change traffic light states, and schedule road maintenance.

## When to use this category
Use this category when:
- You need to report or manage an emergency incident
- You need to dispatch emergency resources (fire trucks, ambulances, police units)
- You need to find available resources near an incident location
- You need to estimate response times or redirect existing resources
- You need to retrieve incident or resource status information
- You need to change traffic light states or schedule road maintenance windows

## Mandatory workflow
1. Read this big skill first to understand the overall system
2. Read the relevant small skill for the specific tool you need
3. Call the tool with proper parameters
