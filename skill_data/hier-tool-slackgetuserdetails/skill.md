## Typical scenarios
- Checking colleague's status
- Viewing user profiles
- Finding contact information

## Tool-call workflow
1. Get user_name (must start with @)
2. Call tool with user_name

## Parameters
**Required:** user_name (starts with @)

## Parameter aliases
user_name: username, member, person

## Call examples
1. "Get details for @john.doe"
2. "Check status of @project-manager"
3. "View profile for @new-hire"
