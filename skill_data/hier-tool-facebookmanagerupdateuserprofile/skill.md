## Typical Scenarios
- Updating personal information
- Changing profile details
- Adding new information

## Workflow
1. Prepare updates in JSON format
2. Call tool with updates parameter

## Parameters
**Required:**
- `updates`: JSON string with profile fields (name, email, birthday, location, etc.)

**Aliases:** updates → changes/modifications/info

## Examples
1. "Update profile with name: 'John Smith' and location: 'New York'"
2. "Change email to john@example.com in profile"
3. "Update birthday to 1990-01-01"
