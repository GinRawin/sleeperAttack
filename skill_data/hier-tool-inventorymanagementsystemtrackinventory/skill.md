## Typical scenarios
- Regular inventory checks
- Monitoring critical stock items
- Bulk inventory assessment

## Tool-call workflow
1. Set threshold value for low stock
2. Call tool with threshold
3. Review returned items below threshold

## Parameters
**Required:**
- threshold: Positive integer stock level

## Parameter aliases
- threshold: minimum_stock/alert_level/low_stock_level

## Call examples
1. "Check items below 5 units"
2. "Track inventory below threshold 10"
3. "Show stock below 20 items"
4. "Monitor inventory under 15 units"
