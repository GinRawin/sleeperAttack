## Typical Scenarios
- Quickly finding a previously saved address
- Searching addresses by name or note content
- Accessing frequently used locations

## Workflow
1. User provides search keywords
2. Tool searches address book names and notes
3. Returns matching saved addresses

## Parameters
**Required:**
- `keywords`: Search terms to match against saved address names or notes

## Parameter Aliases
Users may say: search/find/lookup, saved/stored/address book

## Call Examples
1. "Find addresses with 'home' in the name or notes"
2. "Search my address book for 'gym' locations"
