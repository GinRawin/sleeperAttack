## Typical Scenarios
- Saving home, work, or frequently visited locations
- Creating a personalized list of favorite places
- Storing addresses with notes for future reference

## Workflow
1. User provides address details and optional note
2. Tool saves to address book
3. Address becomes searchable via GoogleMapSearchAddressBook

## Parameters
**Required:**
- `name`: Address label (e.g., "Home", "Office", "Gym")
- `address`: Full address in 'street, city, zip' format
- `note`: Descriptive note about the location

## Parameter Aliases
Users may say: label/title/place name, location/place address, description/memo/comment

## Call Examples
1. "Save my home address: 123 Main St, Anytown, 12345 as Home with note 'Primary residence'"
2. "Add work address: 456 Oak Ave, Business City, 67890 named Office, note 'Weekdays 9-5'"
