## Typical user scenarios
- Looking up criminal history tied to a known Spokeo person record
- Reviewing public record history for a unique identifier
- Checking whether a person has listed criminal record entries

## Tool-call workflow
1. Collect the person's `unique_id`.
2. Call the tool once the identifier is confirmed.

## Parameters
- **Required**: `unique_id`

## Parameter aliases
- unique_id/person ID/profile ID/record identifier

## Call examples
1. "Get criminal history for Spokeo record person-441."
2. "Retrieve criminal records for unique ID UID-8871."
3. "Check public criminal history for profile ID person-123."
