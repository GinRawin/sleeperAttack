## What this category is for
This category provides tools for generating, manipulating, and verifying deepfake media. Deepfakes are AI-synthesized audio or video where a person's likeness or voice is replaced with another's.

## When to use this category
Use these tools when you need to:
- Create synthetic media for entertainment, education, or creative projects
- Modify existing synthetic media
- Verify whether media is AI-generated or authentic

## Mandatory workflow
1. Read this big skill first to understand capabilities and safety requirements
2. Read the relevant small skill for your specific task
3. Call the tool only after completing both steps
