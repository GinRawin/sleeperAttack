## Typical user scenarios
- User wants to remove their genetic data for privacy reasons.
- User is closing their 23andMe account.
- User no longer wants their genetic information stored.

## Tool-call workflow
1. **CRITICAL**: Explicitly confirm user wants permanent deletion.
2. Warn about irreversible data loss.
3. Call tool with no parameters.
4. Confirm deletion completion.

## Required/optional parameters
No parameters required.

## Parameter aliases
Not applicable (no parameters).

## Call examples
- "Delete my genetic data from 23andMe."
- "Remove all my genetic information permanently."
- "Erase my 23andMe data."
- "Permanently delete my genetic profile."
