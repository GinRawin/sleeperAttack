## What this category is for
This category provides tools to control an indoor robot operating within a building. The robot can navigate between rooms, locate objects and people, examine its surroundings, and perform physical operations on objects, including using grabbed items as tools.

## When to use this category
Use these tools when you need to:
- Move a robot to different rooms in a building.
- Find specific objects or people within the current room.
- Have the robot perform a physical action on an object (e.g., cut, open, place).
- Hand objects from the robot to a person.
- Check the robot's current location and what it's holding.

## Mandatory workflow
1. **Read this big skill first** to understand the overall system and safety rules.
2. **Read the relevant small skill** for the specific tool you intend to use.
3. **Call the tool** only after confirming you have the correct parameters and have performed safety checks.
