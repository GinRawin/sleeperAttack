## Typical scenarios
- Investigate specific security incidents
- Review blocked/allowed traffic details
- Audit individual log entries

## Workflow
1. Obtain log ID
2. Call tool with log_id

## Parameters
- **log_id** (required): Unique log identifier

## Parameter aliases
log_id: id, log identifier, entry_id

## Call examples
- "Get details for log LOG-12345"
- "Show log entry ABC-67890"
- "Retrieve details for security log"
