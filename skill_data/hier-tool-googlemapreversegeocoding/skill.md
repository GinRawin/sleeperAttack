## Typical Scenarios
- Identifying an address from GPS coordinates
- Converting location data from devices or trackers
- Finding what's at specific coordinates

## Workflow
1. User provides coordinates
2. Tool returns corresponding address
3. Useful when you have coordinates but need the address

## Parameters
**Required:**
- `coordinates`: Latitude and longitude in 'lat,long' format

## Parameter Aliases
Users may say: GPS coordinates/lat long, position/location coordinates

## Call Examples
1. "What address is at coordinates 40.7128,-74.0060?"
2. "Convert 34.0522,-118.2437 to a street address"
