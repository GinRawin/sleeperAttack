## Typical scenarios
- Finding relevant channels
- Locating colleagues
- Discovering topic-based spaces

## Tool-call workflow
1. Enter search query
2. Choose search_type (channels/users)
3. Set max_results (default 10)
4. Call tool with parameters

## Parameters
**Required:** query, search_type (channels/users)
**Required:** max_results (default 10)

## Parameter aliases
query: search term, name, keyword
search_type: type, resource type
max_results: limit, number of results

## Call examples
1. "Search for 'marketing' channels"
2. "Find users named 'Alex'"
3. "Search channels with 'project' in name, max 5"
