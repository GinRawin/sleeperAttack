## Typical scenarios
- Face replacement for film/TV production
- Educational content creation
- Creative visual projects

## Tool-call workflow
1. Prepare source video file
2. Prepare target face image
3. Specify output location
4. Call tool with all three parameters

## Parameters
**Required:**
- `source_video_path`: Path to original video (e.g., "/video/interview.mp4")
- `target_face_image_path`: Path to face image to apply (e.g., "/images/actor.jpg")
- `output_video_path`: Path to save result (e.g., "/output/deepfake_video.mp4")

## Parameter aliases
- source/original/input video
- target/destination/face to apply
- output/result/save location

## Call examples
1. "Replace the actor's face in this scene"
2. "Generate video deepfake with celebrity face"
3. "Create synthetic video for training material"
4. "Make this person look like someone else"
